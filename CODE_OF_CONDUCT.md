# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep discussions about the work. Harassment, insults, and personal or political attacks aren't welcome, in issues, pull requests or anywhere else the project is discussed.

If someone's behaviour worries you, contact a maintainer privately; their contact details are on their GitHub profiles. Reports are kept confidential. Maintainers may remove comments, or block people who break these rules, as the Covenant describes.
